# Observer End-to-End Workflow

The first public workflow is intentionally narrow and complete:

```text
Import or identify public material
  → verify its manifest and hash
  → inspect the page/transcription version
  → run the separately released GP29 instrument
  → view exact inputs, parameters, and output
  → export a deterministic run record
  → verify a published known-control package
```

The foundation release establishes the evidence and identity contracts. GP29 `v0.1`, the corpus-manifest verifier, and `RC-0001` will complete the executable workflow through separate reviewed releases.

Every public result page will use the same approachable layer:

- **Claim** — the smallest conclusion.
- **Why it matters** — context without expanding the claim.
- **Evidence** — the material observations.
- **Method** — exact operations and parameters.
- **Controls** — positive, negative, shuffled, and family-size context.
- **Limitations** — what the result does not establish.
- **Reproduce** — deterministic instructions and environment.
- **Status** — evidence and publication state.

Expedition storytelling may link to these records, but it never replaces them. Narrative pages remain clearly separated from dry evidence objects.
