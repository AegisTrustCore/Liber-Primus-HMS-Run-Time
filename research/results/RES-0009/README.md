# RES-0009 — The complete Page 05 board fails the declared direct Page 33 family

Under the declared 640-route family, the complete Page 05 numeric board is not supported as a direct periodic key or 25-column permutation for the 267-rune Page 33 stream: all three calibrated models failed half-transfer, solved-reference, and p <= 0.01 permutation gates.
