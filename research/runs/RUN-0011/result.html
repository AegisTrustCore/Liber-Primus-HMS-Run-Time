CONTROLS

  • Page 73 and Page 74 are established terminal plaintext controls, not HMS-originated discoveries.
  • The declared family contains six complete-segment operations and selects the best without resetting at internal red records.
  • Each terminal control is compared with 500 full-family shuffled inputs using token and vocabulary measures.
  • The public verifier requires exact JSON/CSV agreement and recomputes p as 1/(500+1).

INTERPRETATION

The segment-wide runtime recognizes both known terminal operators when they are in the declared family. This validates the instrument as a control but does not establish an operator for any unsolved segment.

LIMITATIONS

  • Both plaintexts and their operations were already known; this is a positive control, not a new translation.
  • The public package retains the complete terminal-control ledger but not the private typed event streams needed to rerun transformation from source glyphs, so reproduction is PARTIAL.
  • Success on two terminal controls does not prove that every LP2 segment uses one of the six operations.
  • This package does not publish the unsolved-segment best-output ledger or forward selector experiments.
