# E1059 — FROZEN NEXT SLICE

## Title

Corpus-wide OutGuess false-positive calibration and intentional-embedding detector

## Motivation

E1058 proved that the Page-17/Page-21/Page-43 `41408 / 58152` family is generated by a constant all-`FF` false header and a carrier-capacity threshold. The next experiment must determine whether any other canonical LP page contains a genuine OutGuess embedding distinct from this artifact family.

## Frozen corpus

- All 75 canonical page scans, Pages 00–74.
- Known positive controls: every historically verified OutGuess payload in LP1, including Page 08.
- False-header controls: Pages 17, 18, 20, 21, 22, and 43.
- Exact extractor and default-key retrieval implementation frozen from E1058.

## Per-page ledger

For every page record:

```text

raw four-byte header
decoded seed
decoded declared length

complete / partial
missing bytes

capacity margin

```

## Primary tests

1. Cluster all decoded headers and identify repeated false-header attractors.
2. Compare positive controls against negatives using source-only carrier features.
3. Measure JPEG coefficient parity and magnitude-conditioned LSB imbalance.
4. Run matched nulls that preserve coefficient magnitude, component, block position, and page-region class while randomizing eligible parity bits.
5. Determine whether each claimed extraction is distinguishable from its page-specific null distribution.
6. Reserve one known positive payload as a fully held-out detector test.

## Acceptance

An intentional embedding candidate must satisfy all of the following:

- non-attractor raw header or independently anomalous embedding statistics;
- complete extraction not explained by capacity threshold alone;
- stable result under an independent implementation;
- detector transfer to the held-out positive control;
- matched-null familywise significance;
- structured output, independently checkable binary object, or a frozen prediction about an unread region.

## Prohibitions

- No decryption search over the E1058 false bodies.
- No arbitrary keys or password dictionaries.
- No promotion based only on completion, entropy, repeated seed, or output length.
- No English fragment scoring before an intentional embedding is established.

## Failure condition

If only the known LP1 positive payloads separate from the null and all LP2 outputs remain in the false-attractor family, OutGuess is removed from the active LP2 key-channel hypothesis.
