# Releases and Reports

HMS maintains separate release tracks:

- Software: semantic versions such as `v0.1.0`
- Research: identifiers such as `RR-0001`, `EXP-0001`, and `PL-0001`
- Public Expeditions: identifiers such as `XPD-0001`

A software release does not automatically publish private research. A research release does not automatically publish private tool source.

Available public run packages:

- [Public Reproduction Runs 001](PUBLIC_RUNS_001.md) — bounded OpenPGP artifact and synthetic verifier reproductions; no advanced LP routes or candidate solves.
