# Start here: the 75-page Liber Primus corpus

> Seventy-five leaves are registered. Fifty-eight belong to the later book. A page is not a solution, and a repeated shape is not a signal.

This path takes a new reader from historical identity to a reproducible public result without requiring prior knowledge of HMS Endeavour.

## 1. Learn what the number 75 means

HMS uses a 75-page composite working corpus:

- pages `00`-`16`: 17 LP1/earlier pages;
- pages `17`-`74`: 58 LP2 pages; and
- total: 75 page carriers.

Do not describe the full set as a single 75-page historical release. See the [timeline](TIMELINE.md).

## 2. Check identity before interpretation

Read [Cicada 3301 and the historical OpenPGP key](../../CICADA_3301.md). The full historical fingerprint recorded by HMS is:

```text
6D85 4CD7 9333 22A6 01C3  286D 181F 01E5 7A35 090F
```

A copied name, key block, image, or cryptic voice is not proof of authorship. HMS is independent and does not possess Cicada 3301's signing authority.

## 3. Locate a page

Use the [page index](PAGE-INDEX.md). It lists all 75 HMS page numbers, their working segment, and the public ledger for each page. Pages 32, 72, and 73 also have public audit dossiers.

The index is a map, not a translation catalog. A ledger records what a run observed; it does not turn an observation into plaintext.

## 4. Verify the carrier identity

If you lawfully obtain a candidate copy of the page images, compare every file against the [canonical page manifest](../../research/runs/RUN-0008/historical/canonical_page_manifest.csv). Do this before resizing, recompressing, enhancing, or testing the images.

Follow [source and verification guidance](SOURCE-AND-VERIFICATION.md). A visually identical JPEG can have different bytes and can produce different steganographic output.

## 5. Read one complete public result

Begin with [RSET-0003: E1059 default-key OutGuess closure](../../research/runsets/RSET-0003/START-HERE.md).

The result establishes only this:

- the declared procedure was applied across the registered 75-page carrier set;
- the known controls separated as expected;
- no LP2 page separated from the matched false-attractor distribution; and
- the exact default-key branch is closed as an active LP2 route on those carriers.

It does **not** establish that LP2 contains no hidden data or that Liber Primus is solved.

## What comes next

The next public work is not a claim of translation. It is stricter carrier-level reproduction, page-specific hypothesis registration, control-first testing, and publication of both positive and negative results through the release gate.

When you submit a hypothesis, state the exact page, carrier hash, transcription/version, transformation, key assumptions, expected output, falsification condition, and reproduction command. That is how a clue becomes testable evidence.
