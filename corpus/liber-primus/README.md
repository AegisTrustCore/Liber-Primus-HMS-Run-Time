# Liber Primus: complete 75-page working corpus

This directory is the public navigation layer for the complete HMS Endeavour working corpus. It registers every page from `00.jpg` through `74.jpg`, identifies the two corpus segments, and connects each page to its public provenance and extraction ledger.

It does **not** claim that all 75 pages were one historical release or that the corpus is solved.

## Corpus definition

| HMS page range | Count | Working segment | Meaning |
|---|---:|---|---|
| `00`-`16` | 17 | LP1 | Earlier Liber Primus material retained as known/control and corpus material |
| `17`-`74` | 58 | LP2 | The 58-page Liber Primus release and the primary unresolved corpus |
| **Total** | **75** | HMS composite | The reproducible page set used by HMS experiments |

The 75-page count is therefore an **HMS working-corpus count**. The 58-page count refers to LP2. These numbers are related, but they are not interchangeable.

## Image-file status

The image bytes are not copied into this repository. The pages are registered by stable hashes and source references because redistribution rights for the third-party archive have not been established. This repository's Apache-2.0 license does not grant rights to Cicada 3301 or other third-party material.

That boundary preserves a complete, auditable corpus map without falsely relicensing the source pages. If a redistribution-cleared source is established, the images can be evaluated as a separate, reviewable release.
