# Internal-Source Audit Interface

This public directory reports audit scope and status without publishing private source paths, raw notebooks, premium code, or Vault material.

The complete supplied Personal Research tree audit found 1,322 files totaling 3,837,489,779 bytes. A separate active-workspace scan found 889 Runtime run directories and dozens of page-specific documents and experiment definitions. Counts do not imply independent evidence: generated reruns, duplicates, controls, and superseded artifacts are expected.

Public outputs are reviewed aggregate reports and claim inventories, not bulk exports of private source material.
