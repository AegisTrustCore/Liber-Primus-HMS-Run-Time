# GP29 deterministic core v0.0.1

Status: **INTERNAL TESTING — developer source only**

GP29 calculates explicit Gematria Primus prime values. It is a calculator, not a decoder, language detector, or proof that an output is plaintext.

## Run it

```text
python scripts/hms_runtime.py self-test
python scripts/hms_runtime.py gp29 "ᚠᚢᚦ" --mode runes
python scripts/hms_runtime.py gp29 "F U/V TH" --mode tokens
python scripts/hms_runtime.py gp29 "F U/V TH" --mode tokens --job
```

Use `--file PATH` instead of inline text for UTF-8 input files.

## Input rules

- Rune mode accepts the 29 frozen Unicode runes and whitespace.
- Token mode requires tokens separated by whitespace, commas, semicolons, or pipes.
- Continuous Latin text is deliberately rejected because multi-letter GP29 sounds make implicit segmentation ambiguous.
- Accepted aliases include `U`/`V`, `C`/`K`, `I`/`J`, `IO`/`IA`, `S`/`Z`, and `NG`/`ING`.
- Auto mode chooses rune mode when it sees a supported rune; otherwise it uses token mode.

## Frozen table

```text
ᚠ ᚢ ᚦ ᚩ ᚱ ᚳ ᚷ ᚹ ᚻ ᚾ ᛁ ᛄ ᛇ ᛈ ᛉ ᛋ ᛏ ᛒ ᛖ ᛗ ᛚ ᛝ ᛟ ᛞ ᚪ ᚫ ᚣ ᛡ ᛠ
```

Values are the first 29 primes, from 2 through 109. The canonical sounds and aliases are stored beside the table in `hms_tools/gp29.py` and exercised by public tests.

## Output contract

Every calculation returns normalized runes and tokens, per-rune metadata, rune count, GP sum, sum modulo 29, and a SHA-256 digest over canonical JSON. With `--job`, the calculation is wrapped in `HMS_RUNTIME_JOB_V1` and `HMS_RUNTIME_RESULT_V1`.
