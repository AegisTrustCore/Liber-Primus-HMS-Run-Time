# HMS GP29 Calculator v0.1.0-rc.1

Status: **RELEASE CANDIDATE — gate pending; not publicly released**

## What it is

GP29 calculates explicit Gematria Primus prime values. It is an offline calculator, not a decoder, language detector, translation, or proof that an output is plaintext.

## Download

No public download is authorized yet. The Windows x64 portable ZIP has been built and locally qualified, but it must not become a GitHub or Patreon asset until the bound software gate is approved.

Candidate artifact: `HMS-GP29-v0.1.0-rc.1-Windows-x64-portable.zip`

## Quick start

Inside the candidate package:

1. Double-click `HMS-GP29.exe` for the desktop interface.
2. Enter supported runes, or explicit sound tokens such as `F U/V TH`.
3. Choose the input mode and select **Calculate**.
4. Use **Export JSON** to save the complete deterministic result.
5. Power users can run `HMS-GP29-CLI.exe --help` or `HMS-GP29-CLI.exe self-test`.

Developer source remains runnable with:

```text
python scripts/hms_runtime.py self-test
python scripts/hms_runtime.py gp29 "ᚠᚢᚦ" --mode runes
python scripts/hms_runtime.py gp29 "F U/V TH" --mode tokens --job
```

## Supported systems

- Candidate desktop and CLI package: Windows 10/11 x64.
- Developer source: CPython 3.12 using the standard library.

The candidate executables do not require Python, `pip`, source checkout, an HMS account, or a network connection.

## Input rules

- Rune mode accepts the 29 frozen Unicode runes and whitespace.
- Token mode requires tokens separated by whitespace, commas, semicolons, or pipes.
- Continuous Latin text is deliberately rejected because multi-letter GP29 sounds make implicit segmentation ambiguous.
- Accepted aliases include `U`/`V`, `C`/`K`, `I`/`J`, `IO`/`IA`, `S`/`Z`, and `NG`/`ING`.
- Auto mode chooses rune mode when it sees a supported rune; otherwise it uses token mode.

## Frozen table

```text
ᚠ ᚢ ᚦ ᚩ ᚱ ᚳ ᚷ ᚹ ᚻ ᚾ ᛁ ᛄ ᛇ ᛈ ᛉ ᛋ ᛏ ᛒ ᛖ ᛗ ᛚ ᛝ ᛟ ᛞ ᚪ ᚫ ᚣ ᛡ ᛠ
```

Values are the first 29 primes, from 2 through 109. Canonical sounds and aliases are frozen in `hms_tools/gp29.py` and exercised by public tests.

## Output format

Every calculation returns normalized runes and tokens, per-rune metadata, rune count, GP sum, sum modulo 29, and a SHA-256 digest over canonical JSON. Runtime mode wraps the calculation in `HMS_RUNTIME_JOB_V1` and `HMS_RUNTIME_RESULT_V1`.

## Limitations

- The calculator does not segment continuous Latin text.
- It does not select transforms, routes, keys, or candidate plaintext.
- `CALCULATION_ONLY` output is not research verification.
- The current desktop build targets Windows x64 only.

## Verify the candidate

The package contains internal `SHA256SUMS`. The exact executable package passed CLI self-test, deterministic Runtime-job execution, GUI headless self-test, and internal checksum verification on the declared Windows environment. Two clean package builds produced an identical ZIP digest.

The release manifest and public checksum remain authoritative only after human approval. Rebuilding after approval invalidates the approval.

```text
python scripts/build_gp29_windows.py
```

The pinned build dependency is PyInstaller 6.22.0. The builder fixes the source epoch and Python hash seed, creates both standalone executables, writes internal checksums, and produces a deterministic ZIP envelope.
