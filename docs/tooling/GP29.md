## What it is

GP29 calculates explicit Gematria Primus prime values. It is an offline calculator, not a decoder, language detector, translation, or proof that an output is plaintext.

## Quick start

Inside the candidate package:

1. Double-click `HMS-GP29.exe` for the desktop interface.
2. Enter Latin text such as `CICADA`, supported runes, or explicit sound tokens such as `F U/V TH`.
3. Choose the input mode and select **Calculate**.
4. Use **Export JSON** to save the complete deterministic result.
5. Power users can run `HMS-GP29-CLI.exe --help` or `HMS-GP29-CLI.exe self-test`.

Developer source remains runnable with:

```text
python scripts/hms_runtime.py self-test
python scripts/hms_runtime.py gp29 "ᚠᚢᚦ" --mode runes
python scripts/hms_runtime.py gp29 "F U/V TH" --mode tokens --job
```

## Input rules

- Rune mode accepts the 29 frozen Unicode runes and whitespace.
- Latin mode accepts continuous Latin text and applies a frozen longest-alias rule. For example, `THING` becomes `TH ING`; this is deterministic transliteration, not language interpretation.
- Token mode requires tokens separated by whitespace, commas, semicolons, or pipes.
- Accepted aliases include `U`/`V`, `C`/`K`, `I`/`J`, `IO`/`IA`, `S`/`Z`, and `NG`/`ING`.
- Auto mode chooses rune mode when it sees a supported rune, token mode when every separated token is explicit, and Latin mode otherwise.

## Frozen table

```text
ᚠ ᚢ ᚦ ᚩ ᚱ ᚳ ᚷ ᚹ ᚻ ᚾ ᛁ ᛄ ᛇ ᛈ ᛉ ᛋ ᛏ ᛒ ᛖ ᛗ ᛚ ᛝ ᛟ ᛞ ᚪ ᚫ ᚣ ᛡ ᛠ
```

Values are the first 29 primes, from 2 through 109. Canonical sounds and aliases are frozen in `hms_tools/gp29.py` and exercised by public tests.

## Output format

Every calculation returns normalized runes and tokens, per-rune `L`, `R`, prime, `N`, and `Q` values, documented aggregate sums and residues, and a SHA-256 digest over canonical JSON. The format is declared by [gp29-result.schema.json](../../schemas/gp29-result.schema.json). Runtime mode wraps the calculation in `HMS_RUNTIME_JOB_V1` and `HMS_RUNTIME_RESULT_V1`.

The registers are defined without hidden parameters:

- `L = index`, from 0 through 28 in canonical GP29 order;
- `R = (-L) mod 29`;
- `prime` is the corresponding member of the first 29 primes;
- `N = prime mod 29`; and
- `Q = floor(prime / 29)`, so `prime = 29Q + N`.

## Limitations

- Latin segmentation is mechanical longest-alias transliteration, not a phonetic or linguistic judgment. Use token mode when exact segmentation matters.
- It does not select transforms, routes, keys, or candidate plaintext.
- `CALCULATION_ONLY` output is not research verification.
- The current desktop build targets Windows x64 only.
