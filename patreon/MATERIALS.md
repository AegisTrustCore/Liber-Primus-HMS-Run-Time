# Member Material Packaging

Member material is packaged by purpose and release status, not by copying the private workspace into Patreon.

## Package classes

| Package | Minimum contents | Normal destination |
|---|---|---|
| Dispatch | Progress summary, current release state, next gate, public links | Pilgrim+ |
| Experiment download | Approved inputs, parameters, outputs, limitations, checksums | Navigator+ |
| Research packet | Extended report, experiment index, controls, negative branches, references | Cartographer+ |
| Structured dataset | Schema, provenance, license/rights note, checksum manifest, data dictionary | Cartographer+ |
| Frontier preview | Experimental interface, instability warning, feedback channel, expiration/supersession note | Admiral |
| Build package | Version, access level, installation/use notes, limitations, support boundary | Eligible tool tier |

## Excluded from member uploads

- Credentials, tokens, private keys, or local paths
- Unreviewed personal correspondence or member data
- Raw Vault exports
- Proprietary server entitlement logic
- Third-party material without redistribution rights
- Claims presented without their evidence status and limitations

Every downloadable package should have a durable package ID, version, SHA-256 manifest, audience, status, and related public record where one exists.
