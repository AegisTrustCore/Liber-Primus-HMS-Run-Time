# PUBLIC-001 — The HMS Public Evidence Layer

Status: **POSTED 2026-08-12**

Live post: https://www.patreon.com/AegisTrustCore/posts/hms-public-layer-166540390

HMS Endeavour is building a public evidence layer for Liber Primus research. GitHub will show what is actually released, how claims are classified, what controls reproduce known material, what remains unresolved, and what has been corrected.

There is no tagged HMS GitHub release yet. The foundation is currently a release candidate under review. It does not claim that the Liber Primus corpus has been solved.

When the foundation is released, the public repository will contain the research index, source-audit summary, Page 32/72/73 dossiers, release policy, and instrument status registry. Advanced member material will be organized through Patreon and the hosted HMS environment as it becomes available, while approved truth claims remain part of the public evidence record.
