# Tier Release Checklist

Before releasing a post, download, tool, build, or dataset to a Patreon tier:

- [ ] The audience and minimum tier are explicit.
- [ ] Current capability is separated from planned capability.
- [ ] Software and research release states are not conflated.
- [ ] Research language matches the public evidence taxonomy.
- [ ] Known controls are not described as HMS discoveries.
- [ ] Negative results state the exact rejected family.
- [ ] Corrections link the superseded interpretation.
- [ ] Inputs, rights, personal data, and private paths were reviewed.
- [ ] Downloads have a package ID, version, and SHA-256 manifest.
- [ ] Vault and server-only material remain excluded.
- [ ] The corresponding instrument status permits this audience.
- [ ] Public GitHub evidence is linked when available.
- [ ] The post states limitations and the next gate.
- [ ] An administrator approved publication.
- [ ] Patreon was checked after posting before the manifest was marked `POSTED`.
