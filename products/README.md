# HMS product registry

[`manifest.json`](manifest.json) is the machine-readable authority for product status, access level, dependency order, release channel, and the next required gate.

## Product layers

| Layer | Products | Distribution |
|---|---|---|
| Public foundation | Evidence archive, schemas, controls, releases | GitHub |
| Public instruments | GP29, Corpus Verifier, Expedition client, Endeavour Lite | GitHub after approval |
| Member workstation | HMS Endeavour Runtime Environment and advanced research modules | Approved Patreon tiers |
| Hosted research | Liber Runtime Beta, Auto Explore, contextual AEGIS | Planned hosted service |
| Developer platform | Batch engine, Advanced GP, solver, sockets/API, Plugin SDK | Planned; capability-gated |

Marketing copy never overrides the manifest or the [instrument registry](../instruments/README.md). A product marked `IN_DEVELOPMENT`, `INTERNAL_TESTING`, or `RELEASE_CANDIDATE` is not an available download.
