## What it does

GP29 performs deterministic Gematria Primus calculations using the documented 29-rune table and `L`, `R`, prime, `N`, and `Q` registers. It provides:

- English A-Z input where each character remains separate;
- deliberate longest-match Latin-sound input;
- exact separated sound tokens and canonical rune input;
- a visible, searchable, selectable Gematria Primus alphabet;
- a readable results dashboard and per-rune breakdown;
- raw JSON, readable-summary copy, JSON copy, and CSV export;
- non-persistent session history and quick examples; and
- standalone desktop and command-line applications.

It is a calculator, not a decoder, plaintext detector, translator, solver, or Liber Primus solve claim.

## English H behavior

- `H` in English-letter mode is the H rune, prime / GP value `23`.
- `TH` in English-letter mode is `T + H`, prime / GP sum `82`.
- `TH` in Latin-sound mode is the single TH rune, prime / GP value `5`.

## Quick start

1. Verify the ZIP SHA-256.
2. Extract the ZIP into a normal folder.
3. Read `START-HERE.txt`.
4. Launch `HMS-GP29.exe`.
5. Use English-letter mode for ordinary words or select exact tokens/runes from the alphabet.
6. Run `HMS-GP29-CLI.exe self-test` before relying on CLI calculations.

## Privacy and security

GP29 is offline and contains no telemetry, accounts, automatic updates, sockets, or network features. Session history exists only in memory and disappears when the app closes.

The final ZIP reproduced byte-for-byte across two local builds, passed source and packaged tests, passed independent GitHub Windows qualification, and produced no Microsoft Defender detections. The executables are not Authenticode-signed; Windows may show an Unknown Publisher or reputation warning. Verify the SHA-256 before running them.

## Acceptance limitation

The repository owner reviewed the packaged application through iterative UAT and explicitly approved release. Human acceptance occurred on the Windows build workstation rather than a separate clean machine; GitHub-hosted clean Windows runners independently repeated packaging and executable checks. This limitation is retained in the qualification record.
