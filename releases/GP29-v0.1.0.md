# HMS GP29 Calculator v0.1.0

Release state: **PENDING clean-machine acceptance and explicit human approval**

## What it is

GP29 is an offline Gematria Primus calculator for ordinary Latin text, the 29 supported runes, and explicit sound tokens. It reports the canonical `L`, `R`, prime, `N`, and `Q` registers, their documented aggregates, and a deterministic result digest.

It is a calculator, not a Liber Primus decoder, translator, plaintext detector, solver, or solve claim.

## Quick start

1. Verify the ZIP checksum before extracting it.
2. Extract the ZIP to a normal folder.
3. Read `START-HERE.txt`.
4. Launch `HMS-GP29.exe` for the desktop interface.
5. Run `HMS-GP29-CLI.exe self-test` before relying on CLI calculations.

## Documented examples

- Latin input `CICADA` produces prime/GP sum `340`.
- Explicit tokens `F U/V TH` produce prime/GP sum `10`.
- The first rune in canonical order produces prime/GP sum `2`.

The package also includes `EXAMPLE.txt` for UTF-8 file input.

## Output

The desktop application provides readable output and JSON export. The CLI provides JSON and deterministic Runtime-job output. Inputs are read but never modified.

## Privacy and network boundary

GP29 is offline. It has no accounts, telemetry, hosted solver, Patreon authentication, network requests, sockets, or automatic update system.
